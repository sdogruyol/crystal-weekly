About
Crystal Weekly is a weekly newsletter about Crystal Programming Language.
Curated by Serdar Doğruyol. Crystal Weekly aims to bring the best resources, blog posts, community events and anything Crystal to your inboxes.
The source code of this site is hosted on GitHub and you can contribute to it. If you'd like to submit something to be included in the next issue, open a github issue.
